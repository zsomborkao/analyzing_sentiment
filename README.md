# Sentiment Analysis

This project explores sentiment analysis using Python and Natural Language Processing (NLP).

The goal is to analyze text data and identify the sentiment expressed in the text, such as positive, negative, or neutral.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- Natural Language Processing (NLP)

## Project Structure
- `02_analyzing_sentiment.ipynb` – Jupyter Notebook containing the sentiment analysis workflow.

## Goals
- Explore and preprocess text data.
- Analyze sentiment in textual data.
- Practice data analysis and NLP techniques.
